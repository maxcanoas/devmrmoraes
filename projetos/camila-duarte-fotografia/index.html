Início / Trabalho / Camila Duarte (fictício)

Uma fotógrafa que não existe, e um site que existe.

Projeto fictício

Camila Duarte não é uma pessoa real e não existe cliente por trás deste trabalho. Inventei o briefing e construí o site do zero como exercício. Está no portfólio porque o código e as decisões de projeto são reais, mas nenhum resultado comercial aqui aconteceu de verdade.

Por que este exercício.

Site de portfólio criativo funciona por regras diferentes das de um site institucional. Ali a hierarquia é invertida: a imagem carrega a mensagem, o texto apoia, e o layout precisa sumir para não competir com o trabalho exposto.

É o oposto do que eu costumo construir, e foi por isso que escolhi praticar nisso. O briefing que eu escrevi para mim mesmo foi de uma fotógrafa autoral com anos de estrada — casamento, retrato, maternidade, família — precisando de um lugar próprio para mostrar o trabalho e receber contato.

Persona inventada, mas com as restrições que um projeto real teria.

O problema técnico.

O desafio central de um portfólio visual é o equilíbrio entre peso e velocidade. Fotografia em qualidade suficiente para valorizar o trabalho é pesada, e página pesada afasta o visitante antes de a primeira imagem aparecer.

Resolvi com carregamento adiado do que está abaixo da dobra, dimensão declarada em toda imagem para o layout não pular enquanto carrega, e uma galeria que abre em tela cheia sem carregar a versão grande antes de alguém pedir.

A navegação some quase por completo: sem menu carregado, sem chamada piscando, sem nada disputando atenção com a foto.
