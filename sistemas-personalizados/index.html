    Acompanhar o processo real

Perguntas frequentes.

Não sai mais barato comprar um sistema pronto?

Muitas vezes sim, e nesses casos eu falo. Sistema de prateleira ganha quando o seu processo é igual ao de todo mundo: emitir nota, controlar ponto, fechar caixa. Sob medida ganha quando adaptar a empresa ao software custaria mais do que construir o software para a empresa.

Os dados que já existem se perdem?

Não. Migração faz parte do projeto: eu leio o que está na planilha ou no sistema antigo e trago para o novo. O que costuma aparecer nessa hora é inconsistência que já existia e ninguém tinha visto, como cliente cadastrado duas vezes com nomes diferentes.

E se eu precisar de uma funcionalidade nova depois?

Foi para isso que o sistema nasceu em módulos. Funcionalidade nova é um módulo novo, com escopo e valor próprios, sem mexer no que já está funcionando.

Minha equipe é resistente a mudança. Isso funciona?

Funciona se a equipe participar do desenho, e é por isso que a primeira etapa é acompanhar quem faz o trabalho. Sistema desenhado só com a chefia costuma virar aquela tela que todo mundo preenche depois, de qualquer jeito, para o relatório fechar.

Web ou desktop?

Depende de onde o trabalho acontece. Desktop faz sentido quando tudo roda dentro da empresa e há equipamento a integrar; web faz sentido quando gente de fora precisa acessar, ou quando há mais de um ponto. Eu recomendo na primeira conversa, com o motivo.
